1. Аккордеон

Що таке HTML?

HTML — мова розмітки, яка використовується для створення структури вебсторінок.

Для чого потрібен CSS?

CSS відповідає за зовнішній вигляд сторінки: кольори, шрифти та розташування елементів.

Що таке JavaScript?

JavaScript додає вебсторінкам інтерактивність та дозволяє реагувати на дії користувача.
